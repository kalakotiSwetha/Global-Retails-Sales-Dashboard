# 🌍 Global Retail Sales Dashboard | Power BI

> An interactive Business Intelligence dashboard built with Power BI to analyze global retail sales, profitability, customer segments, products, discounts, returns, and regional performance.

---

## 📌 About the Project

The **Global Retail Sales Dashboard** is a data analytics and visualization project created using **Microsoft Power BI**.

The project analyzes the **Global Superstore dataset** to understand how sales and profit are distributed across different regions, markets, countries, product categories, sub-categories, and customer segments.

The dashboard provides an interactive way to explore retail performance through KPIs, charts, maps, slicers, and business-focused analysis.

---

## 🎯 Business Objective

The purpose of this project is to build a centralized dashboard that helps users quickly understand retail business performance.

The dashboard focuses on:

- Sales performance
- Profitability
- Order performance
- Regional performance
- Product performance
- Customer segments
- Discounts
- Returns
- Time-based trends

---

## ❓ Business Questions

The dashboard was designed to answer the following questions:

### Sales Performance

- What is the total sales generated?
- Which regions contribute the most sales?
- Which markets have stronger sales performance?
- Which categories and sub-categories generate higher sales?
- How does sales performance change over time?

### Profitability

- What is the total profit?
- Which regions generate higher profit?
- Which categories are more profitable?
- Which products have low or negative profit?
- What is the overall profit margin?

### Product Performance

- Which products generate higher sales?
- Which products generate higher profit?
- Which categories perform better?
- Which sub-categories contribute significantly to sales?

### Customer Analysis

- Which customer segments contribute more sales?
- Which segments generate more profit?
- How does customer performance vary across regions?

### Discount Analysis

- How are discounts distributed?
- Which categories receive higher discounts?
- How do discounts relate to sales?
- How do discounts relate to profit?

### Return Analysis

- How many orders were returned?
- What is the return rate?
- Which regions have more returned orders?
- Which categories have higher return activity?

## 🗂️ Data Tables

### 1. Orders

The **Orders** table contains the primary transaction-level information.

It is used for:

- Sales analysis
- Profit analysis
- Product analysis
- Customer analysis
- Discount analysis
- Regional analysis
- Time-based analysis

### 2. Returns

The **Returns** table contains returned order information.

It is used to calculate and analyze:

- Returned Orders
- Return Rate
- Returns by region
- Returns by category
- Return patterns

### 3. People

The **People** table contains regional and manager-related information and provides additional context for regional analysis.
